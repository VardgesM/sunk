# Historical telemetry presentation

- `/history` is a frontend-only, read-only screen available to the same authenticated roles as Tags. It searches metadata from the existing `tagsApi.all()` client. Name, key and unit are searchable; at most 80 matching options are mounted at once. The existing Tag details history remains available and reuses `TagHistory`.
- Presets cover 1h, 6h, 24h, 7d and the existing 30d range. Custom local dates are applied explicitly and sent as UTC ISO timestamps. The existing 366-day validation, `getHistory` endpoint, `max_points=1000` and `limit=1000` are unchanged.
- The applied/requested interval is visible. Changing a Tag/range aborts the old request and hides its chart. Delayed responses cannot relabel a previous Tag's history. Loading, error and empty states reserve chart space; Retry repeats the failed applied interval.
- The plot still uses numeric lines, boolean steps, null gaps and `connectNulls=false`. No samples, outage boundaries or interpolation are invented. Missing recorded intervals are not proof of continuous coverage. Invalid-quality/mixed buckets retain existing server semantics.
- Counts describe returned points/buckets and the API's stored-record count. No global Latest/Min/Max/Average is computed: downsampling, gaps and truncated results can make an unqualified summary misleading. Data details retain quality and source information.
- Tooltips show local time, exact numeric text when available, units and quality. Bucket tooltips identify aggregation and original bucket bounds. A bounded, scrollable DOM tooltip uses `textContent` for all API data, never interpolated HTML ([ECharts security guidance](https://echarts.apache.org/handbook/en/best-practices/security/)). The same formatter is used by Dashboard chart widgets; their configuration, ranges, polling and history requests are unchanged.
- Charts resize with their container and reduce tick density on narrow plots. The slider changes the view only; Reset zoom is keyboard-accessible and does not fetch data. The chart has a textual description and quality/gap counts; it is not a full keyboard-navigable raw-data table.
- On touch devices tooltips open on completed taps (not touch-start), with an eight-second hide delay; mouse tooltips retain hover behavior and the short hide delay. A compact scrollable tooltip occupies the opposite half of the chart, away from the tapping finger. Tooltips appear without a fade that can obscure a brief tap.
- No new WebSocket subscriptions, retention behavior, server queries or history storage changes are introduced. Configuration/history APIs, permissions and non-chart feature pages are unchanged.
